## 🐍 Python & Exploratory Data Analysis (EDA)

### [TikTok EDA Project](https://www.google.com/search?q=https://github.com/shammatthews-life/Tiktok-EDA)

* **Description:** An Exploratory Data Analysis and data visualization project for the TikTok data science team focused on uncovering what distinguishes claim videos from opinion videos.
* **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Tableau
* **Key Highlights:** Handled missing data, evaluated heavy-tailed distributions in engagement metrics, and built executive-ready dashboards.

### [Mapping User Churn & Driving Patterns (Waze Project)](https://www.google.com/search?q=https://github.com/shammatthews-life/Mapping-User-Churn-Driving-Patterns)

* **Description:** Conducted deep EDA on user behavioral data to examine distribution spreads, identify outliers, and evaluate feature metrics like sessions and drives to understand user churn.
* **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn
* **Key Highlights:** Implemented custom helper functions for distribution plotting and applied statistical strategies for outlier handling.

### [NYC TLC Data Analysis: Uncovering Patterns in Taxi Fare Distributions](https://www.google.com/search?q=https://github.com/shammatthews-life/NYC-TLC-Data-Analysis-Uncovering-Patterns-in-Taxi-Fare-Distributions)

* **Description:** Comprehensive exploratory data analysis of New York City Taxi and Limousine Commission (TLC) trip records to investigate fare distributions, payment behaviors, and key operational trends.
* **Tech Stack:** Python, Pandas, NumPy, Data Cleaning, Seaborn
* **Key Highlights:** Cleaned large-scale trip datasets and visualized spatial-temporal metrics to extract actionable fare pricing insights.
